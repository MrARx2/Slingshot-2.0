# Track Generator Package

Contains the production contents of `Assets/Scripts/TrackGeneration`, excluding the editor test suite.

Included:

- Runtime generation pipeline, planning, topology, feature rules, mesh/collider builders, validation, gravity, race, and stunt scripts.
- Track Generator custom editor and preview-cache scripts.
- Assembly definitions and Unity `.meta` files.
- Current TrackConfig/PostProcess assets and tuning context.

Required Unity packages: Unity Mathematics and Unity Input System.
